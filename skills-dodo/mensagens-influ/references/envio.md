# Confirmação de envio

Mensagem que avisa a influenciadora que o seeding foi feito e o produto está a caminho.

## Estrutura

1. Abertura padrão
2. Aviso de envio (sempre na voz da marca: "o seeding da Jescri já foi feito")
3. Dado prático em negrito: transportadora + código de rastreio
4. Previsão de entrega quando houver
5. Pedido pra confirmar recebimento
6. Fechamento

## Campos em negrito
- Código de rastreio
- Data prevista de entrega
- Nome do produto, se for envio de peça específica fora de coleção
- Link de rastreio (quando curto)

## Variações por situação

### Seeding genérico (coleção, vários produtos)
```
oi, [nome]! tudo bem por aí? ☀️

passando para avisar que o seeding da Jescri já foi feito. enviei pelos Correios, com previsão de entrega para *[data]*.

código de rastreio: *[código]*

assim que chegar, me sinaliza por favor? quero garantir que está tudo certo.

obrigadooo 🩵
```

### Envio de peça específica (campanha, ativação pontual)
```
oi, [nome]! tudo bem por aí? ☀️

passando para avisar que a peça da ativação de [mês] já foi despachada. é a *[nome do produto]*, conforme alinhamos.

transportadora: [nome]
código: *[código]*
previsão: *[data]*

me avisa quando chegar pra eu marcar aqui, por favor 🩵
```

### Reenvio (peça anterior teve problema)
```
oi, [nome]! tudo bem por aí? ☀️

passando para avisar que o reenvio da *[peça]* já foi feito. desta vez fui [Correios/transportadora X] com código *[código]*.

previsão de chegada: *[data]*. me sinaliza quando chegar?

obrigadooo 🩵
```

## Regras específicas
- "seeding" em minúscula, sem itálico (palavra já incorporada no vocabulário)
- Não usar "kit", "presente", "mimo" para evitar parecer marketing. É "seeding", "envio", "peça"
- Quando o envio for de coleção inteira, não listar peça por peça. Listar só se for 1 ou 2 itens
- Se a influenciadora já recebeu seedings antes, pode pular o "passando para avisar" e ir direto: "o seeding de [mês] já foi feito"

## O que não fazer
- Não dizer "espero que goste" (parece pedido de aprovação)
- Não pedir feedback do produto na mesma mensagem (separa em outra interação)
- Não antecipar combinação de postagem aqui (briefing vem em mensagem separada)
