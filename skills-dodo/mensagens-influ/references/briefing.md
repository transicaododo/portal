# Briefing acompanhante

Mensagem que segue junto com o documento de briefing em PDF ou link do Drive.

## Princípio

**Mensagem curta.** O briefing tem todos os detalhes. A mensagem só serve para entregar
o documento e abrir canal de dúvida. Não resumir nada do briefing aqui.

## Template base (padrão)

```
oi, [nome]! tudo bem por aí? ☀️

segue em anexo o briefing de [mês], qualquer dúvida é só me falar!
```

É só isso. Sem lista de datas, sem destaque de campanha, sem resumo. Se o Dani quiser
adicionar algo (datas, contexto especial, alerta de mudança), ele adiciona depois,
manualmente.

## Quando o Dani pede explicitamente lista de datas

Se ele disser "monta com as datas" ou "inclui as datas", aí sim listar:

```
oi, [nome]! tudo bem por aí? ☀️

segue em anexo o briefing de [mês], qualquer dúvida é só me falar!

datas:

•⁠  ⁠*reel*: [data] ([dia]) [hora], aprovação no dia [data]
•⁠  ⁠*carrossel*: [data] ([dia]) [hora], aprovação no dia [data]
•⁠  ⁠*stories*: [data] ([dia]) [hora], aprovação no dia [data]
```

Só incluir lista se ele pedir. Default é a versão curta.

## Regras específicas
- Nome = primeiro nome só (Ju, Carol, Lê, Duda)
- Quando listar datas: dia da semana abreviado (seg, ter, qua, qui, sex, sáb, dom)
- Hora no formato simples: "20h", "10h", "12h". Com minutos: "10h30"
- Ordem das ativações (se listar): reel, carrossel, stories 1, stories 2
- Omitir silenciosamente ativações sem data

## O que não fazer
- Não inflar a mensagem com resumo do briefing
- Não anunciar campanhas, destaques, mudanças. Se o Dani quiser dizer algo, ele diz
- Não pedir confirmação de leitura
- Não colocar prazo de resposta para dúvidas
- Não usar travessão
