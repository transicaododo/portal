# Cobrança

Quando a data de aprovação ou postagem já passou. A intenção é firmar sem agredir,
mantendo a relação mas sem suavizar a ponto de esvaziar o ponto.

**Referência cruzada obrigatória:** consultar `/mnt/skills/user/humanizar/references/modo-pepinos.md`
para os princípios de comunicação operacional delicada.

## Estrutura

1. Abertura adaptada (não usa frase padrão completa, ver abaixo)
2. Fato: o que estava combinado, o que aconteceu
3. Impacto prático (quando relevante)
4. Encaminhamento claro
5. Fechamento sem servilidade

## Campos em negrito
- Data combinada que passou
- Nome da ativação
- Novo prazo proposto (se houver)

## Abertura

Cobrança não usa "oi, [nome]! tudo bem por aí? ☀️" porque o emoji solar contradiz o
conteúdo. Usar uma das variações:

- `oi, [nome]! 🤍`
- `oi, [nome], tudo certo? 🤍`
- `oi, [nome] 🤍`

**Sem emoji no fechamento** (regra do Dani: cobrança tem 1 só emoji, no início).

## Variações por atraso

### Aprovação atrasou 1-2 dias
```
oi, [nome]! 🤍

passando aqui porque a aprovação do *[reel/carrossel/stories]* estava marcada para *[data]* e ainda não chegou. me sinaliza como está aí pra eu conseguir organizar o fluxo de feedback.

a data de postagem segue confirmada para *[data da postagem]*.
```

### Aprovação atrasou 3+ dias / risco de afetar postagem
```
oi, [nome]! 🤍

a aprovação do *[ativação]* estava prevista para *[data]* e ainda não recebi. com a postagem marcada para *[data da postagem]*, preciso entender se você consegue enviar até *[novo prazo realista]* ou se vamos precisar remarcar a data de publicação.

me responde quando conseguir, por favor.
```

### Postagem não saiu na data combinada
```
oi, [nome], tudo certo? 🤍

a postagem do *[ativação]* estava agendada para *[data]* às *[hora]* e ainda não subiu. me sinaliza se houve algum imprevisto e quando você consegue publicar?
```

### Conteúdo ainda não veio, briefing já tem semanas
```
oi, [nome] 🤍

passando aqui pra alinhar sobre o briefing de [mês]. as datas de aprovação eram *[data]* e *[data]* e ainda não recebi nenhum conteúdo. precisamos conversar para entender se as ativações ainda vão acontecer ou se vamos reorganizar o cronograma.

quando você puder, me responde para a gente seguir.
```

## Princípios (do modo pepinos)

- Nomear o problema sem dramatizar
- Mostrar o impacto prático
- Encaminhamento claro: o que precisa ser feito, quando
- Manter a relação, manter a autoridade
- Não suavizar a ponto de esvaziar. Não endurecer a ponto de criar atrito

## O que não fazer
- Não começar com "desculpa o incômodo" (você não está incomodando, você está cobrando
  o que foi combinado)
- Não usar "imagino que tenha sido corrido" sem que ela tenha sinalizado isso
- Não dizer "fico no aguardo" (servil)
- Não usar travessão para suavizar
- Não pedir três vezes desculpa por cobrar
- Não terminar com emoji (regra)
- Não acumular várias cobranças numa só mensagem se forem assuntos diferentes
